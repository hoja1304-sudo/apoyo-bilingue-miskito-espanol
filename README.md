# APOYO BILINGÜE MISKITO-ESPAÑOL

Mini aplicación para practicar saludos y normas de clase en miskito y español.

## Vista local

Abre `index.html` en un navegador. Para revisar el diseño como celular, reduce el ancho de la ventana o usa la vista adaptable del navegador.

## Publicación

El flujo de GitHub Actions en `.github/workflows/pages.yml` publica el contenido estático con GitHub Pages cuando se envía un cambio a `main`.

Las imágenes y el código de la aplicación se incluyen en el sitio. El PDF de apoyo permanece fuera del repositorio.
